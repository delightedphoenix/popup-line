# Step 1: Live "Coming soon" page

**Labels:** slice-1, priority: high · **Milestone:** Slice 1: working line (top priority) · **Depends on:** nothing (first step)

## Goal
Put a blank "Coming soon" page at the app's free public web address, so we know hosting works.

## What to build
- A static `index.html` (plain HTML/CSS, no framework, no build step) that says "Coming soon".
- Firebase Hosting setup in the repo (`firebase.json`, `.firebaserc`) and a deploy with the Firebase CLI.
- Add the Firebase web config using the values Lexie gives you. Don't invent any values. No secrets in the repo.
- A short "How to deploy" section in the README, in plain steps.

## Done when
- [ ] Lexie opens the public address on her phone and sees "Coming soon".

## Out of scope
Any line, database or dashboard features.
